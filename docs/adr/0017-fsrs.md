# ADR 0017: FSRS reviews, replayed from evidence

**Status:** accepted, 2026-11-22

## Context

Reviews used a doubling interval (1, 2, 4, 8… days) for understood
concepts only, and the only review question was the trick. That
interval ignores how well something is actually remembered. Asking one
question type rewards memorising an answer instead of knowing the idea.

## Decisions

1. **FSRS-6 schedules reviews.** Its formulas and default weights are
   ported from
   [open-spaced-repetition/fsrs4anki](https://github.com/open-spaced-repetition/fsrs4anki)
   (MIT, notice kept in `src/knowledge/fsrs.ts`).
   - **Differences:** no fuzz, so the schedule stays deterministic and
     testable.
   - **Rounding:** stability and difficulty are rounded to two decimals
     each step, as in the reference.
   - **Parity:** a golden test, produced by running the reference's own
     functions, guards the port.
2. **Replayed, never stored.**
   - **The replay:** a concept's graded evidence, oldest first, becomes
     its memory.
   - **Ratings:** right without a hint is Good, right with a hint is Hard,
     wrong is Again. Easy is never used.
   - **Schema:** the database (P8) stores evidence only, so the scheduler
     can change without migrations.
3. **Learning concepts are scheduled too.** A review a day or two later
   is exactly the retention evidence a learning concept needs to become
   Understood.
4. **Four review kinds rotate:**
   - **When to use it:** distractors are concepts of the same kind.
   - **The trick.**
   - **Rebuild the solution:** the next line of the real solution, with
     distractors only from later lines, so earlier lines can't give it
     away.
   - **How it grows:** from measured growth.

   Concepts without a lesson get "when to use it" only.
5. **A miss shows the refresher** on the spot: the concept's meaning and
   key facts, its card, and a problem to practise. FSRS brings it back
   sooner.
6. **Questions about the concept itself never count as transfer.**
   `inAProblem` excludes placement answers and `problem: "review"`
   answers.

## Consequences

- With default weights, the first review comes after about 2 days.
  Per-student weight optimisation needs much more review history than
  students will have this term, so it's deferred.
- Home shows a Review row whenever anything is due, so its Next item
  never repeats a review.
