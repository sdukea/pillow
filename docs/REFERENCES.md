## Licensing rules

- **MIT:** code and text can be reused, as long as the copyright and license
  notice is kept wherever it's copied.
- **CC BY-SA 4.0** (coding-interview-university, cp-algorithms): copied text
  must credit the source, and the copied material must be released under the
  same license. Pillow's lessons are written by us; use these as research,
  not as text to paste.
- Never copy LeetCode's own problem statements; restate problems in our own
  words, as the lessons already do.
